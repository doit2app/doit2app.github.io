# 그자리 — 고스트 촬영 프로토타입

지난 사진을 카메라 위에 반투명하게 겹쳐 보며 같은 자리·같은 구도로 다시 찍는 앱의 핵심 화면만 만든 프로토타입이에요.
목적은 MVP에서 가장 위험한 부분, **"미리보기에 겹친 고스트와 실제로 저장되는 사진이 정확히 맞는가"**를 실제 기기에서 확인하는 거예요.

## 들어 있는 것

- 첫 사진 찍기 / 갤러리에서 불러오기 (비율 3:4 · 1:1 · 9:16 중 선택)
- 고스트 촬영: 첫 사진·직전 사진 고르기, 3×3 격자
- 고스트 보이는 방식 3가지
  - **겹치기**: 반투명으로 겹치고 투명도 슬라이더로 조절
  - **깜빡이기**: 고스트를 켰다 껐다 해서 어긋난 곳을 찾기
  - **반반**: 경계선 왼쪽은 지난 사진, 오른쪽은 지금 카메라. 경계선을 끌어 옮기고, 선이 끊기지 않고 이어지면 맞은 것
- **맞으면 자동 촬영**: 기울기가 맞은 상태로 0.8초 멈추면 저절로 찍혀요 (맞기 시작할 때 진동, 찍힐 때 한 번 더).
  고스트 사진에 기울기 기록이 없으면(첫 사진, 불러온 사진) 수평만 봐요. 한 번 찍힌 뒤에는 한 번 어긋났다가 다시 맞춰야 또 찍혀요
- 수평계와 기울기 비교: 고스트 사진을 찍을 때의 기울기(좌우·앞뒤)와 지금 기울기의 차이, 1.5° 안이면 초록색
- 찍은 뒤 확인: 슬라이더로 새 사진 ↔ 지난 사진을 섞어 보며 얼마나 맞았는지 보고 저장 또는 다시 찍기
- 앞·뒤 카메라 전환 (앞 카메라는 미리보기처럼 좌우 반전해서 저장)
- 홈에서 넘겨보기 (타임랩스 미리보기), 사진을 길게 눌러 지우기

사진은 앱 폴더(`document/project/photos`)에 긴 변 2048px, JPEG 품질 0.85로 저장해요. 목록(`project.json`)에는 파일 이름만 적어요.

## 실행

```bash
cd ghost-camera
npm install
npx expo start
```

휴대폰의 **Expo Go**(SDK 58)로 QR을 찍으면 바로 열려요. 쓰는 모듈(카메라, 센서, 이미지 편집, 파일, 사진 선택, 슬라이더)이 모두 Expo Go에 들어 있어서 따로 빌드할 필요가 없어요.

## 기기에서 꼭 확인할 것

| 확인할 것 | 방법 | 문제가 있으면 |
|---|---|---|
| 고스트와 저장된 사진이 정확히 겹치는가 | 책상 위 물건을 찍고, 폰을 움직이지 말고 바로 한 장 더 찍기 → 확인 화면에서 슬라이더를 움직여 어긋나는지 | 미리보기가 FILL(가운데를 채움)이 아닌 것. `src/frame.ts`의 `centerCrop`을 기기별로 조정 |
| 비율 3가지 모두 맞는가 | 프로젝트를 지우고 비율을 바꿔 같은 방법으로 | 특히 안드로이드의 9:16 |
| 앞 카메라 좌우 반전 | 셀카로 같은 방법 | `CameraView`의 `mirror` |
| 자동 촬영 | 지난 사진과 같은 자세로 들고 멈추기 → 0.8초 뒤 찍히는가, 손이 떨릴 때 너무 쉽게/어렵게 찍히지 않는가 | `src/align.ts`의 `MATCH_OK`(1.5°), `HOLD_MS`(800ms) 조정 |
| 반반 경계선 | 경계선을 끌 때 부드럽게 따라오는가 | `SplitGhost`의 터치 영역 |
| 수평계 방향 | 폰을 시계 방향으로 돌릴 때 선이 실제 수평을 유지하는가 | `src/useTilt.ts`에서 `roll` 부호를 플랫폼별로 뒤집기 |
| 갤러리에서 불러온 사진 방향 | 세로·가로 사진 각각 불러오기 | 회전 정보(EXIF) 처리 |

기기 2~3대(아이폰 1대, 제조사가 다른 안드로이드 1~2대)에서 확인하는 걸 추천해요.

## 파일

- `App.tsx` — 홈 ↔ 촬영 화면 전환
- `src/screens/CameraScreen.tsx` — 고스트 촬영과 찍은 뒤 확인
- `src/screens/HomeScreen.tsx` — 첫 사진, 사진 목록, 넘겨보기
- `src/frame.ts` — 비율, 가운데 자르기 계산 (정렬의 핵심)
- `src/storage.ts` — 사진 저장·목록
- `src/useTilt.ts` — 가속도계로 기울기 재기
- `src/align.ts` — 맞았는지 판정하는 기준 (자동 촬영)
- `src/components/Overlays.tsx` — 격자, 수평선, 기울기 표시, 반반 나눠 보기

## 실제 앱으로 넘어갈 때 바꿀 것

- 프로젝트 여러 개, 화면 이동은 Expo Router로
- 목록 저장은 JSON → `expo-sqlite`
- 썸네일 따로 만들기, 갤러리 앨범에도 저장하기, 알림, 내보내기
