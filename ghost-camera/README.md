# 그자리 — 고스트 촬영 프로토타입

지난 사진을 카메라 위에 반투명하게 겹쳐 보며 같은 자리·같은 구도로 다시 찍는 앱의 핵심 화면만 만든 프로토타입이에요.
목적은 MVP에서 가장 위험한 부분, **"미리보기에 겹친 고스트와 실제로 저장되는 사진이 정확히 맞는가"**를 실제 기기에서 확인하는 거예요.

## 들어 있는 것

- 첫 사진 찍기 / 갤러리에서 불러오기 (비율 3:4 · 1:1 · 9:16 중 선택)
- 고스트 촬영: 첫 사진·직전 사진 고르기, 3×3 격자, 앞·뒤 카메라
- 고스트 보이는 방식 3가지: **겹치기**(투명도 조절) · **깜빡이기** · **반반**(경계선을 끌어 비교)
- **배경 일치도**: 지금 카메라 화면과 지난 사진의 배경이 얼마나 맞는지 실시간으로 % 표시
- **방향 안내**: "→ 오른쪽으로", "↑ 위로", "뒤로 한 걸음"처럼 어느 쪽으로 움직이면 맞는지 알려 줌
- **기울기 비교**: 지난 사진을 찍을 때와 지금의 좌우·앞뒤 기울기 차이 (1.5° 안이면 초록)
- **맞으면 자동 촬영**: 기울기와 배경이 모두 맞은 채로 0.8초 멈추면 저절로 찍힘 (진동으로 알림)
- **찍은 뒤 자동 보정**: 새 사진이 조금 옮겨졌거나 크기가 다르면 잘라서 지난 사진 자리에 맞춤. 켬/끔으로 비교 가능
- 홈에서 넘겨보기 (타임랩스 미리보기), 사진을 길게 눌러 지우기

사진은 앱 폴더(`document/project/photos`)에 긴 변 2048px, JPEG 품질 0.85로 저장해요. 목록(`project.json`)에는 파일 이름만 적어요.

## 배경 비교는 이렇게 해요 (`src/match.ts`)

1. 지난 사진과 카메라 화면을 작은 흑백 격자(가로 32칸)로 줄여요. 카메라 화면은 카메라 스레드에서 0.2초마다 뽑아요.
2. 색 대신 **윤곽선**을 비교해요. 아침·저녁처럼 밝기가 달라도 선은 그대로라서요.
3. **가장자리에 무게를 더** 줘요. 찍는 대상(아이, 식물)은 보통 가운데에서 변하고, 배경은 가장자리에 있어서요.
4. 그대로 겹쳤을 때의 상관계수가 **일치도**예요.
5. 지난 사진을 조금씩 옮기고 키우거나 줄여 가장 잘 맞는 위치를 찾으면, 그 차이가 **방향 안내**가 돼요.
6. 찍은 뒤에는 가로 96칸으로 더 정밀하게 같은 계산을 해서 **자동 보정**해요.

## 실행

카메라를 VisionCamera로 바꿔서 **Expo Go로는 열 수 없어요.** 빌드한 앱을 설치해야 해요.

- **안드로이드**: EAS에서 만든 APK를 휴대폰에서 내려받아 설치 (`eas build -p android --profile preview`)
- **아이폰**: Apple 개발자 계정으로 로그인해 빌드하고, 기기를 등록해야 설치할 수 있어요
  ```bash
  npx eas-cli@latest device:create      # 아이폰 등록 (처음 한 번)
  npx eas-cli@latest build -p ios --profile preview
  ```
- 코드를 고치면서 바로바로 보고 싶으면 개발용 빌드(`--profile development`)를 설치하고 `npx expo start`로 연결해요.

## 기기에서 꼭 확인할 것

| 확인할 것 | 방법 | 문제가 있으면 |
|---|---|---|
| 고스트와 저장된 사진이 정확히 겹치는가 | 책상 위 물건을 찍고, 폰을 움직이지 말고 바로 한 장 더 찍기 → 확인 화면에서 슬라이더를 움직여 어긋나는지 | 미리보기가 FILL(가운데를 채움)이 아닌 것. `src/frame.ts`의 `centerCrop`을 기기별로 조정 |
| 비율 3가지 모두 맞는가 | 프로젝트를 지우고 비율을 바꿔 같은 방법으로 | 특히 안드로이드의 9:16 |
| 앞 카메라 좌우 반전 | 셀카로 같은 방법 | `CameraView`의 `mirror` |
| 자동 촬영 | 지난 사진과 같은 자세로 들고 멈추기 → 0.8초 뒤 찍히는가, 손이 떨릴 때 너무 쉽게/어렵게 찍히지 않는가 | `src/align.ts`의 `MATCH_OK`(1.5°), `HOLD_MS`(800ms) 조정 |
| 배경 일치도 | 같은 자리에서 몇 %가 나오는지, 옆으로 비켜서면 얼마나 떨어지는지 | `src/match.ts`의 `SCORE_OK`(50%) 조정 |
| 방향 안내 | 오른쪽으로 비켜섰을 때 "← 왼쪽으로"가 나오는가 (반대로 나오면 부호 문제) | `src/match.ts`의 `guideText` |
| 자동 보정 | 일부러 조금 비켜 찍은 뒤 보정 켬/끔 비교 | `src/autoAlign.ts`의 기준 |
| 실시간 비교 속도 | 일치도 숫자가 0.2초마다 바뀌는가, 폰이 뜨거워지지 않는가 | `LIVE_INTERVAL_MS`, `LIVE_GRID_W` |
| 반반 경계선 | 경계선을 끌 때 부드럽게 따라오는가 | `SplitGhost`의 터치 영역 |
| 수평계 방향 | 폰을 시계 방향으로 돌릴 때 선이 실제 수평을 유지하는가 | `src/useTilt.ts`에서 `roll` 부호를 플랫폼별로 뒤집기 |
| 갤러리에서 불러온 사진 방향 | 세로·가로 사진 각각 불러오기 | 회전 정보(EXIF) 처리 |

기기 2~3대(아이폰 1대, 제조사가 다른 안드로이드 1~2대)에서 확인하는 걸 추천해요.

## 파일

- `App.tsx` — 홈 ↔ 촬영 화면 전환
- `src/screens/CameraScreen.tsx` — 고스트 촬영과 찍은 뒤 확인
- `src/screens/HomeScreen.tsx` — 첫 사진, 사진 목록, 넘겨보기
- `src/frame.ts` — 비율, 가운데 자르기 계산 (정렬의 핵심)
- `src/storage.ts` — 사진 저장·목록
- `src/useTilt.ts` — 가속도계로 기울기 재기
- `src/align.ts` — 기울기가 맞았는지 판정하는 기준
- `src/match.ts` — 배경 비교 (일치도, 방향 안내)
- `src/frameSample.ts` — 카메라 프레임에서 흑백 격자 뽑기
- `src/grayImage.ts` — 저장된 사진을 흑백 격자로 읽기
- `src/autoAlign.ts` — 찍은 뒤 자동 보정
- `src/components/Overlays.tsx` — 격자, 수평선, 기울기 표시, 반반 나눠 보기
